## 📹 Apna Video Call

Apna Video Call is a web-based video conferencing application designed to enable users to communicate through real-time video meetings.

✨ Features

- User registration and login
- Create and join video meetings
- Real-time audio and video communication
- Meeting history
- Protected application pages
- Responsive user interface

🛠️ Technologies

- React.js
- JavaScript
- Node.js
- Express.js
- WebRTC
- WebSocket
- MongoDB
